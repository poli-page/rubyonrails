## Versioning

`poli_page-rails` shares its major.minor with the Poli Page API: gem `0.13.x` passes API contract `0.13` and requires `poli-page` `~> 0.13.0`. Patch numbers are free. A change of the API contract, a new feature, and a raise of the minimum Ruby or Rails version are each a minor. The repo's [`RELEASING.md`](https://github.com/poli-page/rubyonrails/blob/main/RELEASING.md) has the details.
